# Mental Health Sentiment Analyzer

A 3rd Year NLP Engineering Project for multi-class mental health 
classification of social media posts.

## Categories Detected
- Depression, Anxiety, Bipolar Disorder, PTSD, OCD, Suicidal Ideation, Neutral Wellness

## Results
- Accuracy: 99.82%
- Macro F1-Score: 0.9983

## Setup
pip install scikit-learn scipy nltk matplotlib seaborn pandas numpy

## Run
python mental_health_sentiment_analyzer.py
